# ISUCON competition workspace

This repository is the minimal entry harness for improving the final valid
score. Import the day's application source here; install `kaizen` separately.
Practice repositories start from a dedicated private fork of this harness.

Before team work, load the installed plugin's `team` skill:
Claude Code: `/kaizen:team`. Codex: use the team skill from the kaizen plugin.
Operating policy, coordination, deployment and benchmark procedures, templates,
and control-host tooling belong to that plugin. Do not copy them into this repo.
Installation commands are in README.md.

Start lightly: confirm the human's mode, deadline, target and communication
channel; follow the team skill's short START guide, join once, inspect current
queue/discussion, and take the next evidence-backed task. Open detailed guides
when that operation is needed, not as a complete onboarding reading list.
Use fast feedback in practice and competition: reason about direction, make
bounded changes quickly, and use existing focused checks and benchmark tools.
Keep the main session responsive; delegate long independent work when useful.
Ordinary authorized work does not need a new approval at each stage. Preserve
the plugin's ownership, correctness, measurement and recovery rules.
Retrospectives are available when useful or requested, not a mandatory contest
ceremony. Keep infrastructure logic, credentials and run-specific evidence out
of this harness.
